# Quorum widget: critique and review items, and what changed

The first build's brief, mockup and code were lost; `known.md` kept the outcomes. Part A lists the two design critics'
items as known.md records them and where this design carries each. Part B lists the review findings against the first
build (known.md's eight bugs) and how the design prevents them. Part C lists what this rebuild's own screenshot and
collision rounds found and changed.

## A. Design critiques (two critics, before the first build)

| Item                                                                 | What changed                                                                                                                                                                       |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A replica's state was decided at the W-th ack (wrong)                | Arrival rule: it holds what reached it by the moment the read request reaches it (`landAt ≤ readAt`); W 1 R 1 is a real stale read (17 ms early), the default repairs R3            |
| Too many panels                                                      | One stage: replicas, the read-set strip right under the reader, then a compact latency section                                                                                     |
| No visible geometry                                                  | Writer over zone A, reader under zone C, line lengths follow round trips, round-trip chips on every line; no heavy zone band                                                        |
| W and R as steppers off the picture                                  | Handles on the drawing, stops ONE, QUORUM, ALL (unnamed levels by number, never "W 4, 4"), each with "survives k down · writes succeed x%"                                         |
| Replicas as toggles with no state model                              | A roving button group of cards, four state pips (up, down, stops mid-write, back), a name with state and next action, a hint naming the next state, 44 px targets at 252 px with N 5 |
| The overlap had no climax                                            | The BOTH ring is the motion climax; the pill is the heaviest mark; handles quieter                                                                                                 |
| The guarantee mixed up with the one drawn read                       | The strip counts `C(n − h, r)` of `C(n, r)` with × per set and rings the drawn read separately (`thisReadUnsure`)                                                                  |
| "R + W > N" oversold                                                 | One muted sentence under the strip: not linearizable (racing reads, last-write-wins)                                                                                               |
| Latency hidden in prose                                              | Log axis 1 to 200 ms, write acks and read answers, W-th and R-th ringed, the repair as a bar                                                                                       |
| Height jumped with content                                           | Height depends only on width and N: 846 at N 3, 880 at N 5 at 620 px; phones as short as collisions allow                                                                          |
| Wording                                                              | "2 live, 3 needed", "2 reachable, 3 needed" (short "x of y needed"); `old` and neutral pills label the read's time; "both acked and answered"; R + W order everywhere                |
| Timeouts called failures                                             | "timed out", never "failed"; the reveal says the outcome is unknown, hence idempotent retries                                                                                       |
| E1 to E6 wording and answers                                         | As known.md (brief 3), answer positions 3, 1, 2, 1, 3; every number a slot; E3's choices ascending; E4's correct choice first; E6 states its bounds as the status line does          |
| Lesson text                                                          | Brief 1, engine work: the R-answers sentence, "reported as failed (a timeout)", "usual choice"                                                                                     |

## B. Review findings against the first build (prevent up front)

| #   | Finding                                                                                     | How this design prevents it                                                                                                                                                                                  |
| --- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Giveaways while asking on many surfaces                                                    | One `hiding()` map from a question's regions to every surface (brief 3's table), held through the answer's play; the no-answer sweep also looks for false claims, motion on and off, no repair particle      |
| 2   | `fieldset.group` padding beat `.n-control`; N control over the stage below wide            | `fieldset.group.n-control`; a 320 px layout check                                                                                                                                                            |
| 3   | Chips, line labels, latency dots tracked by `$index`                                       | Tracked by replica id wherever order changes mid-play                                                                                                                                                        |
| 4   | Latency labels on the grid line, struck through                                            | Stage-coloured ground under every label and name, grid under text, markers end at their ring, opaque dots, labels inside the plot with fallbacks; `shoot.cjs` flags grid through text without a ground       |
| 5   | Look-here tags clipped or missing                                                          | 3 px off the border, 16 px off corners; frame edges, just inside, the gutter outside, beside the frame; the sweep checks every experiment at 11 widths                                                        |
| 6   | Read-side marks at t = 0                                                                   | Each read-side mark has an appear time from the model (brief 2, Motion)                                                                                                                                      |
| 7   | The unreachable × on a repair arc (N 5 W 1 R 4 back/down/back/up/up, 400 px); stand-in reply drawn as `fly` | The × is placed where no arc, line, mark or text is; that setting is in the sweep; a timed-out stand-in's reply is `applied`                                                                   |
| 8   | Plays paused by one stage's visibility                                                     | The play clock follows the widget host's visibility and the page's                                                                                                                                           |

## C. This rebuild's rounds (screenshots read at 1280, 390 and 320 px, both themes; `shoot.cjs` and its sweeps)

| Found                                                                                                         | Changed                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| The "repair" label sat on R3's read line (it shared the line's owner, so placement ignored the line)            | Labels get their own owner; placement checks every line, its own arc included                                                 |
| Phone lane labels sat on the grid                                                                              | Grounds under them; the grid starts below                                                                                     |
| The W-th label and a dot name overlapped above a ringed dot                                                    | Names go under the dots on a ground; ring labels try right, left, above, upper right and upper left with their own owner       |
| The hidden strip sentence used the home-ack count ("the 1 that acked"), a hint for E5                         | It uses W: "Does every read of 2 meet the 2 that acked?" (neutral and true)                                                   |
| Heights varied by state (the legend lost rows while hiding)                                                    | Legend rows and the longest overlap sentence are reserved per width; heights are one value per width and N                    |
| Desktop stage 872, then 848, not 846                                                                           | Shorter fans, a two-row legend, the reader box without its empty band; 846 and 880 at 620 px                                  |
| "Look here" found no place for the writer and reader on phones                                                 | The house candidate order plus beside-the-frame positions; the reader's outline is one frame round box, pill and BOTH caption |
| With N 5 at 252 px an unreachable replica's read line left from the card's edge and cut the neighbour's chip   | Dashed lines leave from under the chip row                                                                                    |
| The unreachable × covered a "40 ms" chip (it checked lines only, and ignored every line sharing "reader")      | It checks text and marks too, with a token of its own                                                                         |
| A timed-out write's strip said "a read that misses them returns v7" under "0 of 3 can miss"                    | Two sentences by count; the headline is muted when the write did not succeed                                                  |
| "R1, R2 and R3 both acked and answered" overflowed 252 px                                                      | Small type, then "R1, R2, R3 acked and answered"                                                                               |
| The axis lost "200 ms" (the unit) at 252 px                                                                    | The unit label is placed first; ticks give way to it                                                                          |
| No room for "acked 3 ms" at 252 px                                                                             | Phone lanes have room above the dots for ring labels                                                                          |
| The focus hint covered R2's "4 ms" chip                                                                        | The hint goes above the card only where it covers no text, else below; the next state's pip gets a dashed ring              |
| Toggles wrapped to three lines at 320 px                                                                       | Toggle text a step smaller (body-s)                                                                                           |
| The handle letters read as small text                                                                          | W and R in the accent at 15 px (handles are UI, the only purple on the stage)                                                 |
| known.md names a `failed write` verdict without defining it                                                    | Defined: a timed-out write no replica applied (1,116 settings), so v8 exists nowhere and only a retry lands it                 |
| E4 and E5 ask after their write has happened                                                                   | Their act is `run: 'read'`, the framework addition known.md names; E1 to E3 play `write-read`                                 |

| Describe's last column scrolled at 320 px                                                                      | Compact cells and heads ("R1", "Got"); it fits without scrolling                                                              |
| While E2 asked, the strip said "Nothing was written, so there is nothing to miss" and "3 of 3": the answer       | `write` hides the strip too ("Which reads can miss v8 depends on how the write ends"); a `noAnswer()` sweep scans every asking picture |
| The header legend's "repair" line hinted at E4's answer                                                        | The legend drops "repair" while repairs are hidden                                                                            |
| "Even then, R + W > N..." dangled after a neutral or negative first sentence                                   | "R + W > N alone is not linearizable: ...", true in every case                                                                |
