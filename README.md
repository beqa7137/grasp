# Storage Engines widget (`storage-engine`) design

Brief, mockup, model and checks for the redesigned Storage Engines widget (REDESIGN.md R41).

- `brief.md`: the design brief. `changes.md`: each critique item and what changed.
- `model.js`: the rough cost model and the experiments. `node enum.cjs` prints every number and runs the checks.
- `mockup.html`: the mockup (needs `fonts/`, copied from `@fontsource-variable/inter` and `jetbrains-mono`).
- `node shoot.cjs`: screenshots to `shots/` and the sweeps. `--no-sweep`, `--sweep-only`, `--only=`, `--widths=`.
