# Sharding widget (`hash-ring`) design

Brief, mockup, model and checks for the redesigned Sharding widget (REDESIGN.md R41).

- `brief.md`: the verdict, the mechanism, the picture, the experiments, accessibility, the prevention list, lesson fixes.
- `changes.md`: what the design's own checks and self-critique found, and what changed.
- `model.js`, `enum.cjs`: the exact model and its enumeration (`node enum.cjs`).
- `mockup.html`, `shoot.cjs`: the mockup and its screenshots, collision report and sweeps (`node shoot.cjs`; fonts go
  in `fonts/`, copied from `@fontsource-variable/inter` and `@fontsource-variable/jetbrains-mono`).
- `one.cjs`, `sheet.cjs`: one state, or several side by side.
