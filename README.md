# Reliability widget (`availability`) design

Brief, mockup, model and checks for the redesigned Reliability widget (REDESIGN.md R41).

- `brief.md`: the design brief (verdict and mechanism, the picture, the experiments, accessibility, the prevention list,
  interview answers, lesson text fixes).
- `changes.md`: what the first round's checks and critique found, and what changed.
- `model.js`: the exact model, the simulated year and the experiments. `node enum.cjs` prints and checks them.
- `mockup.html`: the live mockup (copy Inter and JetBrains Mono from `@fontsource-variable` into `fonts/` first).
  `node shoot.cjs` renders every state to `shots/` and runs the sweeps.
